# Glossary — Voucher Denomination Catalog

| Term | Definition |
|------|------------|
| **Brand / product family** | Higher-level grouping (operator, gift brand, loyalty program) |
| **Denomination** | Face value amount offered as a sellable voucher product |
| **Eligibility** | Rules for which channels, partners, or regions may sell a SKU |
| **Face value** | Nominal value printed or displayed to the customer |
| **Price book** | Set of wholesale/retail/promo prices effective for a period |
| **SKU** | Stock-keeping unit — catalog identity for a sellable denomination |
| **Variable top-up** | Open-amount product distinct from fixed denomination SKUs |
| **Wholesale price** | Cost to reseller or agent before retail margin |
| **Effective dating** | Start/end validity for catalog or price changes |
